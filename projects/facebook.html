Facebook Data Analysis (Using Power BI)

The Facebook Data Analysis Dashboard provides an interactive visualization of user engagement and activity patterns. It highlights key metrics such as total likes, mobile likes, web likes, gender distribution, and age-wise user activity. The dashboard helps understand user behavior and engagement trends through clear visualizations and data insights.




The analysis helped identify engagement patterns across different user groups. The dashboard provides insights into how age, gender, and platform usage influence Facebook activity, enabling better understanding of audience behavior and supporting data-driven decision-making.
